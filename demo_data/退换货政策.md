# 退换货政策

## 七天无理由退货

依据《消费者权益保护法》第二十五条及《网络购买商品七日无理由退货暂行办法》，消费者通过本店（网络渠道）购买商品，自**签收商品次日起 7 日内**，可无需说明理由申请退货。

### 不适用七天无理由退货的情形
1. 消费者定作的商品；
2. 在线下载或消费者已拆封的数字化商品（如激活码、软件序列号）；
3. 一经**激活或试用后价值贬损较大**的商品（如已激活的手机、笔记本、平板、智能手表等，激活即绑定账号/产生使用数据，无法二次销售）；
4. 已明示的临近保质期或有瑕疵的商品。

> 说明：手机、笔记本、平板、智能手表等数码商品，**一旦激活/联网登录账号，即视为价值贬损较大，不支持七天无理由退货**；未激活、仅拆封查验、外观完好、配件齐全的，可正常退货。

### 商品完好标准
- 商品本身、配件、商标标识齐全；
- 未激活、无个人使用数据残留；
- 未经授权维修、改动，未破坏序列号/防伪标；
- 无难以恢复的外观使用痕迹。

### 退货流程
1. 在订单页面申请「退货退款」，选择退货原因；
2. 客服审核后提供退货地址（7 天无理由退货，**寄回运费由买家承担**，除非商品存在质量问题）；
3. 买家寄回并填写退货物流单号；
4. 仓库签收验货，确认商品完好后，1-3 个工作日内原路退款。

## 质量问题退换货（三包）

商品存在性能故障的，按「三包」规定办理（见《保修三包政策》），**运费由本店承担**，退货运费由买家先行垫付、收货后凭运单凭证退回。

## 换货
- 商品存在质量问题或发错货，支持换货，换货运费由本店承担；
- 换货商品需保持完好，配件齐全。

## 运费规则
| 情形 | 谁承担运费 |
|---|---|
| 7 天无理由退货（非质量问题） | 买家 |
| 质量问题退换货 | 卖家 |
| 发错货 / 漏发 | 卖家 |

## 退款时效
- 未发货订单：申请后立即原路退款；
- 已发货退货：仓库签收验货后 1-3 个工作日退款；
- 退款到账时间以支付渠道为准（银行卡 1-7 个工作日，余额/花呗即时）。
